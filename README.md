# DucatONE

Manuale officina **Fiat Ducato serie 244** (anche Peugeot Boxer / Citroën Jumper) per Windows, basato sui dati del CD eLearn 1.3.2.

## Download

Scarica l'ultima versione dalla pagina **[Releases](../../releases/latest)**:

- `DucatONE-Setup-x.y.z.exe` — installazione completa (programma + dati del manuale)
- `DucatONE-Update-x.y.z.exe` — solo aggiornamento del programma (usato dall'aggiornamento automatico)

Il programma installato controlla da solo questa pagina e propone l'aggiornamento con il pulsante **Aggiorna**.
