# DucatONE

Manuale officina **Fiat Ducato serie 244** (anche Peugeot Boxer / Citroën Jumper) per Windows e Linux, basato sui dati del CD eLearn 1.3.2.

## Download

Scarica l'ultima versione dalla pagina **[Releases](../../releases/latest)**:

- `DucatONE-Setup-x.y.z.exe` — installazione completa (programma + dati del manuale)
- `DucatONE-Update-x.y.z.exe` — solo aggiornamento del programma (usato dall'aggiornamento automatico)
- `DucatONE-Portable-x.y.z.zip` — versione portatile per Windows

**Linux** (Ubuntu, Mint, Debian, Fedora…, 64 bit):

- `DucatONE-x.y.z-x86_64.AppImage` — programma completo in un solo file. Scaricalo, rendilo eseguibile (tasto destro → Proprietà → Consenti l'esecuzione, oppure `chmod +x`) e avvialo con doppio clic.
- `DucatONE-Update-x.y.z-x86_64.AppImage` — solo programma, usato dall'aggiornamento automatico.

Su alcune distribuzioni recenti serve il pacchetto `libfuse2` (`sudo apt install libfuse2`).

Il codice sorgente è nella cartella [`src`](src) (vedi `src/COMPILARE.md`).

Il programma installato controlla da solo questa pagina e propone l'aggiornamento con il pulsante **Aggiorna**.
